PULSTAR application

In the PULSTAR reactor, reactivity is managed through control rods and other parameters. A one-degree increase in coolant temperature can make the reactor subcritical by 3.9 pcm, while withdrawing control rods by the same amount can make it supercritical. This is how reactivity changes are used to hold or adjust the reactor's critical state.

From the source

“…a one degree increase in coolant temperature on the PULSTAR when it is critical would cause the reactor to be subcritical by a reactivity of 3.9 pcm…”
